# sites-project

Portfólio de sites estáticos (HTML, CSS e JS, sem build). Cada site fica em uma pasta própria, e a raiz (`index.html`) lista todos.

| Pasta | Site |
|---|---|
| [`aura/`](aura/) | Aura — Estúdio de beleza |

## Publicação
Publicado pela Vercel a partir deste repositório: cada push na `main` atualiza o site. Como não tem build, na Vercel use o preset **Other**, sem comando de build e com a raiz do projeto como diretório de saída.

## Novo site
Crie uma pasta nova com o `index.html` do site e adicione um item na lista do `index.html` da raiz.
